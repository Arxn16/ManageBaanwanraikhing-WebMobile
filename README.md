# บ้านแว่นไร่ขิง — ระบบจัดการร้านแว่นตา (เวอร์ชัน server)

ระบบเก็บข้อมูลลูกค้า ค่าสายตา และยอดขายของร้าน เปิดใช้ผ่านเบราว์เซอร์ได้ทั้งมือถือ แท็บเล็ต และคอม
ที่ต่อ Wi-Fi วงเดียวกับเครื่อง server ไม่ต้องใช้อินเทอร์เน็ต

## ความสามารถ

- เพิ่ม แก้ไข และลบลูกค้า บันทึกการมาครั้งใหม่ และดูประวัติค่าสายตาทุกครั้ง (R/L: SPH, CYL, AX, VA, ADD, PD/SH)
- แดชบอร์ดยอดขายรายวัน สัปดาห์ เดือน ปี หรือช่วงวันที่ พร้อมยอดค้างชำระ
- ส่งออกข้อมูลเป็น Excel หรือ CSV
- ต้องใส่ PIN ก่อนใช้งาน เครื่องที่ใส่แล้วจะจำไว้ 30 วัน
- สำรองข้อมูลอัตโนมัติวันละครั้ง และมีปุ่มดาวน์โหลดไฟล์สำรองในหน้าเมนู

## เริ่มใช้งานครั้งแรก (Docker)

1. ติดตั้ง [Docker Desktop](https://www.docker.com/products/docker-desktop/) (Mac/Windows) หรือ Docker Engine (Linux)
2. **ย้ายข้อมูลเดิม** ก๊อปไฟล์ `banwaenraikhing.db` จากคอมที่ร้านใช้โปรแกรมเดิม มาวางไว้ที่ `data/banwaenraikhing.db`
   - บน Windows โปรแกรมเดิมเก็บไฟล์ไว้ที่ `C:\Users\<ชื่อผู้ใช้>\AppData\Roaming\banwaenraikhing.db`
   - ถ้าไม่มีไฟล์ ระบบจะสร้างฐานข้อมูลใหม่ให้เอง
3. เปิดไฟล์ `.env` แล้วเปลี่ยน `APP_PIN` เป็นรหัสของร้าน (ถ้าไม่มีไฟล์นี้ ให้ก๊อปจาก `.env.example`)
4. เปิด Terminal ในโฟลเดอร์นี้ แล้วรัน

   ```bash
   docker compose up -d --build
   ```

5. ทดสอบในเครื่องนี้ที่ <http://localhost:3000>

> Mac/Windows: เปิดตั้งค่า Docker Desktop ให้ "Start Docker Desktop when you sign in"
> ระบบจะเปิดเองทุกครั้งที่เปิดเครื่อง

## เปิดใช้จากมือถือ

1. ให้มือถือต่อ Wi-Fi วงเดียวกับเครื่อง server
2. หา IP ของเครื่อง server
   - Mac: รัน `ipconfig getifaddr en0` (หรือดูที่ System Settings → Wi-Fi → Details)
   - Windows: รัน `ipconfig` แล้วดูบรรทัด IPv4 Address
   - Linux: รัน `hostname -I`
3. เปิดเบราว์เซอร์ในมือถือไปที่ `http://<IP>:3000` เช่น `http://192.168.1.10:3000` แล้วใส่ PIN
4. เพิ่มไอคอนไว้ที่หน้าจอ
   - iPhone (Safari): ปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม"
   - Android (Chrome): เมนู ⋮ → "เพิ่มลงในหน้าจอหลัก"
5. **ล็อก IP ของเครื่อง server ในเราเตอร์** (DHCP reservation) ไม่อย่างนั้นถ้า IP เปลี่ยน มือถือจะเข้าไม่ได้

ถ้ามือถือเข้าไม่ได้ ให้ตรวจว่า

- เครื่อง server เปิดอยู่ และ `docker compose ps` แสดงสถานะ `healthy`
- Firewall ของเครื่อง server อนุญาต Docker / พอร์ต 3000
- Wi-Fi ที่ใช้ไม่ใช่ Wi-Fi สำหรับแขก (มักตั้งไว้ไม่ให้เครื่องในวงเห็นกัน)

## คำสั่งที่ใช้บ่อย

| งาน | คำสั่ง |
| --- | --- |
| เปิดระบบ หรืออัปเดตหลังแก้โค้ด | `docker compose up -d --build` |
| ดู log | `docker compose logs -f` |
| ดูสถานะ | `docker compose ps` |
| ปิดระบบ | `docker compose down` |

## สำรองและกู้คืนข้อมูล

- **อัตโนมัติ** ระบบเก็บไฟล์สำรองไว้ที่ `data/backups/` วันละ 1 ไฟล์ เก็บย้อนหลัง 30 ไฟล์ (ปรับได้ที่ `BACKUP_KEEP` ใน `.env`)
- **ด้วยมือ** ที่หน้าเมนูมีปุ่ม "ไฟล์ .db" (ใช้กู้คืน) และ "ไฟล์ JSON" (เปิดอ่านได้)
- ควรก๊อปโฟลเดอร์ `data/backups/` ไปเก็บไว้ที่อื่นเป็นระยะ เช่น USB หรือ Google Drive เผื่อเครื่องเสีย
- อย่าก๊อปไฟล์ `data/banwaenraikhing.db` ขณะระบบทำงาน ให้ใช้ปุ่มดาวน์โหลด หรือปิดระบบก่อน

**วิธีกู้คืน**

```bash
docker compose down
# เอาไฟล์สำรองที่ต้องการมาวางแทน data/banwaenraikhing.db
docker compose up -d
```

## รันแบบไม่ใช้ Docker

ต้องมี Node.js 22.13 ขึ้นไป (แนะนำ 24)

```bash
npm install
npm start
```

ระบบอ่านค่าจากไฟล์ `.env` และเก็บข้อมูลไว้ที่โฟลเดอร์ `data/` เหมือนกัน

## โครงสร้างโฟลเดอร์

| ที่อยู่ | คืออะไร |
| --- | --- |
| `server/` | ตัว server: API, ฐานข้อมูล, PIN, สำรองข้อมูล |
| `public/` | หน้าเว็บ (HTML, JavaScript, CSS, ไอคอน) |
| `styles/input.css` | ต้นฉบับ CSS (Tailwind) |
| `test/` | ชุดทดสอบ API (`npm test`) |
| `data/` | ฐานข้อมูลและไฟล์สำรอง **ไม่ขึ้น git** |
| `legacy-electron/` | เวอร์ชัน Electron เดิม เก็บไว้เผื่อต้องใช้ **ไม่ขึ้น git** |

## สำหรับนักพัฒนา

```bash
npm run dev        # รัน server และรีสตาร์ตเองเมื่อแก้โค้ด
npm run watch:css  # สร้าง CSS ใหม่อัตโนมัติเมื่อแก้ class ใน HTML/JS
npm run build:css  # สร้าง public/css/app.css ครั้งเดียว (Docker ทำให้เองตอน build)
npm test           # ทดสอบ API
```

- ฐานข้อมูลเป็น SQLite (`node:sqlite` ที่มากับ Node.js) ตาราง `customers` เหมือนเวอร์ชันเดิมทุกคอลัมน์
  การมาครั้งถัดไปของลูกค้าเก็บเป็นแถวใหม่ที่มี `parent_id` ชี้ไปที่ลูกค้าหลัก
- API หลัก: `/api/customers`, `/api/customers/:id/visits`, `/api/visits/:id`, `/api/dashboard`,
  `/api/sales?from=&to=`, `/api/export/{csv,xls}`, `/api/backup/{download,json,status}`

## ความปลอดภัยของข้อมูลลูกค้า

- ชื่อ เบอร์โทร ที่อยู่ และค่าสายตาเป็นข้อมูลส่วนบุคคล (PDPA) ห้าม commit `data/` หรือไฟล์ `.db` ขึ้น git
  (`.gitignore` กันไว้ให้แล้ว)
- ใช้ PIN อย่างน้อย 6 หลัก และอย่าเปิดพอร์ตนี้ออกอินเทอร์เน็ต (ไม่ต้องตั้ง port forwarding ที่เราเตอร์)
- ใส่ PIN ผิด 10 ครั้ง ระบบจะล็อก 10 นาที ถ้าเปลี่ยน PIN ทุกเครื่องต้องใส่ PIN ใหม่

## สิ่งที่แก้จากเวอร์ชัน Electron เดิม

- วันที่คำนวณตามเวลาไทย เวอร์ชันเดิมใช้เวลา UTC ทำให้ช่วงก่อน 7 โมงเช้าวันที่เพี้ยน ยอด "เดือนนี้/ปีนี้"
  ไปนับวันสุดท้ายของเดือนก่อนด้วย และตัวกรองรายเดือนไม่นับวันสุดท้ายของเดือน
- แก้ข้อมูลการมาครั้งหนึ่งแล้ว ช่องรายละเอียดไม่ถูกล้าง และไม่ไปบันทึกทับครั้งอื่น
- ลบลูกค้าแล้ว ประวัติการมาทุกครั้งถูกลบด้วย (เดิมค้างอยู่และยังนับในยอดขาย)
- ตัวกรองยอดขายในแดชบอร์ดแสดงผลได้แล้ว และตารางลูกค้าล่าสุดแสดงคอลัมน์ตรงกับหัวตาราง
- บันทึกลง SQLite ทีละรายการแบบปลอดภัย ไฟดับกลางคันข้อมูลไม่พังทั้งไฟล์ (เดิมเขียนทับทั้งไฟล์ทุกครั้งที่บันทึก)
